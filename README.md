# MoveInSync Review Intelligence

Repeatable review-analysis system for the MoveInSync FDE case study: import a CSV of app reviews, audit cleaning, apply transparent rule-based labels, visualise trends by month and app version, rank categories with an editable rubric, validate with manual labels, and export results.

## Evidence note

`data/sample_reviews.csv` is **synthetic demonstration data** (280 rows, generated by `scripts/generate_demo_data.py`). It proves the pipeline runs and illustrates the report format. It is NOT real customer evidence. Replace it with a properly sourced CSV before making claims. See `docs/DATA_COLLECTION.md`.

## Review CSV format

Required: `rating` (1-5), `date` (ISO recommended), `text`.
Optional: `review_id`, `app_version`, `source`, `source_url`.

## What to submit (maps to the case study)

- `docs/RECOMMENDATION.md` - prioritised fixes + Day-1 tickets (replace illustrative tables with real-data run).
- `docs/METHODOLOGY.md` - how you got there + tools used.
- `docs/DATA_COLLECTION.md` - how data was sourced responsibly.
- Dashboard + exports: `streamlit run app.py`, upload real CSV, download classified CSV + Markdown summary.

## How it works

Classifier (`src/classify_reviews.py`) uses ordered keyword rules: Booking > GPS > Notifications > Login/crash > Check-in > Driver/ops > Support > Other. Primary category is first match; all matches kept in `all_matched_categories`. Confidence is heuristic, not calibrated.

Priority default: `0.40 x frequency + 0.35 x severity + 0.25 x confidence`, normalised from sidebar. Severity is a proposed rubric, not company priority. Safety issues escalate separately.

## Limitations

- No internal telemetry included; reviews alone do not prove root cause.
- Labels can be wrong; validate with manual sample + precision/recall.
- Public reviews are self-selected, not representative.
- App does not auto-scrape stores; collection is explicit.

## Deploy (Streamlit Cloud)
1. Push this folder to GitHub (do NOT upload `.venv`, `__pycache__`, `.pytest_cache`).
2. Go to share.streamlit.io, New app, pick the repo, main file `app.py`.
3. The app auto-fetches live Play reviews on launch and falls back to `data/collected_reviews.csv` offline.
